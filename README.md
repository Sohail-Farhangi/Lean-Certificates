# Lean certificates

Each paper directory has an importable Lean project and a standalone source file with a plain-text reader guide.
The modular project’s README documents its pinned dependencies, audit commands, and exact coverage.

The Palomar links point to commits rooted at the modular project, with the repository license. They omit the standalone copies so the registry can apply its source-file limits to the review snapshot. Each snapshot uses the repository root as its project path. External review and registration are separate steps.
